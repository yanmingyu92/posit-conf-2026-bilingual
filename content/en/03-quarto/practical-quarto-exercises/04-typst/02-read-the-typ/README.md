# Your turn 2: read the Typst

`keep-typ: true` is set in `report.qmd`, so rendering keeps the Typst file that
Quarto writes on the way to the PDF.

1. Render, then open `report.typ`. Scroll down to `= Summary`. Everything
   below it is your content.

2. Find a call — it starts with `#`.

3. Look it up in the [Typst reference](https://typst.app/docs/reference/). Say
   in plain words what it does, and whether any **arguments** are being passed
   to it.

4. Again, with another one.
