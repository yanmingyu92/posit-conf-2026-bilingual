# 《现代 R 进阶》教材化编辑计划

作者：Jaime Yan。更新：2026-09-17。

目标读者是已有 R 基础、需要交付分析结果的工作者；临床与制药读者是贯穿示例和核对要求的重要分支。教材的主线是“组织分析 → 交付结果 → 维护代码 → 有证据地应用 AI 与领域工具”。来源工作坊提供素材和署名依据，不作为读者必须参加过的课程或必须拥有的目录结构。

现有 28 章已经具备目标、自测、分层练习、压轴项目和来源映射；已完成的代码修复与测试范围见 [QA-CODE-REPORT.md](QA-CODE-REPORT.md)，格式与术语调整见 [QA-POLISH-REPORT.md](QA-POLISH-REPORT.md)。这些检查确认指定上下文下的代码行为，不等于教材已经提供了全部数据、独立项目、完整答案或真实模型调用验证。

本次新增 [延伸阅读地图](further-reading.qmd)：四个单元各三条阅读线，包含原著或官方文档链接、补充目的、阅读问题和小产物。已核验链接和主要书籍的许可声明；新增引导为原创，仅链接推荐，不翻译或改编 NC／ND 书籍内容。本文件是后续内容编辑计划，不是全书扩写完成报告。

本轮同时完成个人作者署名、原创排版封面、前言、双读者阅读指南、四篇单元导读、训练入口与署名致谢页。网站把书籍、配套训练和会议资料库分为独立入口；仓库仍共用，后续可以拆分部署。

## 贯穿案例与配套材料

本轮已交付一套独立的[多中心数据质量与分析交付训练](companion.qmd#handoff-lab)，含人工模拟输入、起始脚本、参考实现与自动验收。它提供一个完整的通用交接任务，尚不等于下述跨单元贯穿案例或逐章解答已经完成。

建议采用两条案例线。通用主线是“多来源月度运营报告”：原始 CSV／JSON → 清洗和汇总 → 图表 → 报告／应用 → 可复用包。临床分支是“合成研究数据的可核对汇总”：受试者表与访视表 → 明示的教学规则 → 结果数据 → 展示表 → 独立检查。两条线共享函数、测试、环境和交付知识；临床分支所有数据均标注合成，教学规则不冒充临床指南或申报要求。

拟新增配套目录应让读者只下载本教材即可练习。每份数据附字段说明、单位、主键、缺失语义、来源／生成脚本和预期行数；同时提供正常、空、重复、类型异常四类小样本。网络与 AI 示例提供可核对的本地输入和明确标注的人工参考输出，真实请求另列为可选步骤。参考输出不得伪装成实际模型运行结果。

每章答案分两层：copy 练习给完整实现和预期结果；adapt 练习给关键断言与一种可行解；create 和压轴项目提供评阅样例与评分理由，保留多解空间。禁 AI 环节先展示任务和自检标准，参考答案置于单独页面。以下表中的“待补”均尚未实现。

## 实施顺序与完成标准

第一批先解决独立阅读的阻断点：1.2、1.4–1.5 的本地数据；2.3–2.4、2.7–2.8 的完整项目；4.2–4.6 的上游目录依赖；3.1–3.2 的小包起始版本。完成标准是读者不需要另克隆会议仓库，按章说明即可取得数据并运行核心练习。外部服务步骤保留单独条件与跳过说明。

第二批补全两条贯穿案例和逐章概念连接，优先打通 1.1→1.2→1.6→2.8→3.1→3.2，以及临床支线 1.6→3.2→4.7→4.8。每次扩写应增加一种可观察的学习结果，不以字数增长作为验收标准。

第三批完成参考答案、评阅样例与读者试读。请具有基础 R 能力但未接触素材工作坊的读者，从干净目录独立完成一条路径；记录第一次停顿、缺少信息、运行失败和无法判断对错的位置。对临床支线另请熟悉统计编程的审阅者核查计数、缺失处理与证据边界。

每批交付都需记录：新增文件清单、练习输入与预期、实际运行范围、未执行条件、来源和许可。书稿继续保留静态教学代码；可执行验证放在配套项目和 QA 脚本中。本计划中的后续内容完成前，不应对外称“全书已独立运行”“完整答案已齐”或“临床流程已验证”。
