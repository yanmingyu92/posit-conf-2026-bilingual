# 原创训练配套 · Original Practice Labs

作者：**Jaime Yan**。

本目录的原创文字、代码与模拟数据以 [CC-BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) 发布；使用时请保留作者与来源说明。

本目录面向已有 R 基础的数据分析人员，包括临床与制药行业读者。训练围绕独立的数据交付任务组织，不按会议、工作坊或讲师目录编排。当前提供 **1 个完整综合实验**，并非 28 章逐章习题全集。

- [多中心数据质量与分析交付](analysis-handoff/README.md)：从模拟 CSV 开始，建立输入契约、函数化清洗与汇总、异常审计、可复跑检查，并交付一张图和汇总 CSV。

训练案例、代码与数据由本项目原创，适合配合书中函数、迭代、图形和测试章节，也可单独使用。案例中的记录均为人工构造的业务质量观测，不包含患者数据，不代表临床终点或疗效；不能把练习产物当作临床决策或验证交付物。

每个实验分别提供任务说明、starter、参考解答和验收脚本。先完成禁 AI 阶段，再查看参考解答或使用 AI 做审阅。参考解答展示一种可解释方案，验收检查只覆盖明确列出的数据契约。

运行产物统一写入仓库 `.qa/`，避免把生成文件混进训练源目录。详细命令和评分量规见实验说明。
