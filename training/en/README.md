# Original Practice Labs

Author: **Jaime Yan**.

The original text, code, and simulated data in this training collection are published under [CC-BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Preserve the author and source attribution when reusing them.

These materials are for analysts with basic R skills, including clinical and pharmaceutical readers. They are organized around independent data-delivery tasks. There is currently **one complete integrated lab**, rather than a full collection of solutions for all 28 chapters.

- [Multi-site data quality and analysis handoff](analysis-handoff/README.md): begin with a simulated CSV, define an input contract, implement cleaning and summary functions, record exceptions, run reproducible checks, and deliver a chart and summary CSV.

The case, code, and data are original to this project. Use them alongside the chapters on functions, iteration, graphics, and testing, or on their own. All records are artificially constructed business-quality observations. They contain no patient data and represent neither clinical endpoints nor treatment effects. Exercise outputs are not clinical decision tools or validated deliverables.

Each lab supplies a task guide, starter, reference solution, and acceptance script. Complete the AI-off stage before opening the reference solution or using AI for review. The reference illustrates one explainable approach; its checks cover the explicitly listed data contract.

Write generated outputs to the repository's `.qa/` directory, keeping them separate from training sources. See the lab guide for commands and the rubric. In the English download, the original R scripts and CSV are packaged with English guides; both editions use exactly the same code and data.
